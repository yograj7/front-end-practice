CSS Background Attachment

The default value of background-attachment is scroll. The background image moves together with the page whenever the user scrolls. Both the text and the background image scroll at the same speed. The image always stays attached to the element itself. This behaviour is commonly used for normal website sections where no special scrolling effect is required. Since this is the default behaviour, you usually don't need to write background-attachment: scroll; unless you want to make it explicit.

The background-attachment: fixed property keeps the background image fixed relative to the browser window. When the user scrolls the page, the content moves, but the background image remains in the same position, creating a parallax-like scrolling effect. This effect is commonly used in landing pages, travel websites, portfolios, and modern UI designs to make sections more attractive. Be careful while using fixed backgrounds because some mobile browsers may not fully support this behaviour.
